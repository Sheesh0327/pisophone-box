# Changelog

## 1.0.0 (not released yet)
First version of the PisoPhone-only product, made from the PisoHub coin box software.
* Phone slot licensing: 2 free slots, each more needs a P500 license key (up to 12), checked on the box with the owner's public key.
* No router parts: the gateway API (`/api/gateway/*`), the router payment window and the box types (purchased / rental) are gone.
* A new box joins no Wi-Fi until it is set up; the one-file setup program gives it the shop's Wi-Fi and a new admin password over USB.
* One-file setup program with the owner tools, including the slot-license key maker (and re-issue for an erased box).
* Updates come from this repository (`release/update/`).
